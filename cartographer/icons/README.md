Toolbar artwork from [Tabler Icons](https://github.com/tabler/tabler-icons) at revision ed177a0, under the MIT license. The SVGs use white strokes and a 96-pixel raster size so the toolbar can tint them for each state. Regenerate the PNGs with `sips -s format png ICON.svg --out ICON.png` on macOS.
The three layer glyphs adapt Tabler’s box by filling the corresponding face.
